# Changelog

## 1.2.0

- New **Playlists** page: a named list of layouts, with the same durations and
  schedules as before, that any number of displays can show. A display shows
  either a playlist or layouts of its own, and its own list can be saved as a
  playlist from the display's form.
- New **Twitch** element: a channel's live stream, with its chat if wanted and
  an image for when the channel is offline. It plays either with Twitch's own
  player, which needs the screen to open SideDisplay over HTTPS with a host
  name (or on localhost), or as a direct stream, which plays anywhere and skips
  the mature-content prompt but is not an interface Twitch supports.

## 1.1.0

- The sidebar panel can be opened to every Home Assistant user, not only
  administrators: **Settings → Home Assistant users**.

## 1.0.0

- First release.
